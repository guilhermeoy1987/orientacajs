# Orientação a Objetos com JavaScript - EBAC

Este repositório é focado na aplicação dos conceitos de Programação Orientada a Objetos (POO) utilizando as funcionalidades modernas do JavaScript.

## O que foi realizado:
* **Criação de Classes:** Estruturação de moldes para objetos com atributos e métodos específicos.
* **Herança e Reuso:** Implementação de hierarquias entre classes para evitar repetição de código.
* **Encapsulamento:** Organização de dados e lógica interna de forma protegida e coesa.
* **Polimorfismo:** Adaptação de comportamentos herdados para necessidades específicas de cada objeto.

## Tecnologias:
* JavaScript (ES6+)
* Node.js (para execução/testes)
* Git / GitHub (Branch: oo_js)
